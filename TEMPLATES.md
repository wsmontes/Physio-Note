## Re-evaluation Template
```
RE-EVALUATION

Date: [DATE]
Weeks since Initial Eval: [NUMBER]

SUBJECTIVE CHANGES:
- Symptom improvements
- Activity tolerance
- Patient perspective

OBJECTIVE RE-ASSESSMENT:
- Pain: Previous ___/10 → Current ___/10
- ROM: [compare measurements]
- Strength: [compare grades]
- Functional tests: [compare results]

PROGRESS TOWARD GOALS:
Goal 1: [Achieved/In Progress/Not Met]
Goal 2: [Achieved/In Progress/Not Met]
Goal 3: [Achieved/In Progress/Not Met]

UPDATED ASSESSMENT:
- Clinical status
- Response to treatment
- Barriers to progress

REVISED PLAN:
- Continue/modify/progress current program
- New interventions
- Updated frequency/duration
- Revised goals (if needed)
- Estimated time to discharge
```
